# Python Fundamental for ML

This repository contains beginner-friendly Python practice notebooks for building the programming foundation needed for machine learning.

## Contents

- `0.basics/` - Introductory Python exercises and basic problem solving
- `module1.ipynb` - Core Python fundamentals
- `module-2/` - Object-oriented programming concepts
  - `0-basic-oop.ipynb`
  - `1-encapsulation.ipynb`
  - `2-inheritance.ipynb`
  - `3-polymorphism.ipynb`
  - `4-abstraction.ipynb`

## Topics Covered

- Python syntax and basic programs
- Conditional logic
- Simple problem solving
- Object-oriented programming
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Getting Started

1. Open this folder in VS Code or Jupyter Notebook.
2. Install Python if it is not already installed.
3. Open any `.ipynb` notebook and run the cells step by step.

## Recommended Tools

- Python 3
- Jupyter Notebook or JupyterLab
- VS Code with the Python and Jupyter extensions

## Goal

The goal of this course folder is to practice Python fundamentals before moving into machine learning libraries and workflows.
